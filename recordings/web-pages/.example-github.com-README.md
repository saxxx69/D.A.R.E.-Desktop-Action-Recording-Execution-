# GitHub.com Automations

**Template**: Copia questo file a `github.com/README.md` quando crei una nuova pagina web.

## Purpose
Record and execute GitHub workflows (login, navigate repos, create issues, etc.)

## Target
- **URL**: https://github.com
- **Type**: Web Page
- **Platform**: Browser (Chrome/Firefox/Safari)

## Recordings

### run-2026-05-06-login
- **Scenario**: Login to GitHub with credentials
- **Steps**: Open github.com → click login → enter email → enter password → submit
- **Status**: ✓ Complete, validated, ready to execute
- **Notes**: Requires valid credentials in environment variables

### run-2026-05-06-create-repo
- **Scenario**: Create a new repository
- **Steps**: Navigate to new repo page → fill repo name → set visibility → create
- **Status**: ✓ Complete, validated
- **Notes**: None

## Configuration
See `config.json` for site-specific settings and authentication.

## Running Automations

```bash
cd recordings/web-pages/github.com

# List all runs
dare runs list

# View specific run
dare runs show run-2026-05-06-login

# Execute a recording (dry-run first!)
dare execute --run run-2026-05-06-login --live false

# Execute with parameters
dare execute --run run-2026-05-06-login --live true --params "{\"email\":\"user@example.com\"}"
```
