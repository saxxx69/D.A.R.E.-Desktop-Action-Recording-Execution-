# VS Code Automations

**Template**: Copia questo file a `vs-code/README.md` quando crei una nuova app.

## Purpose
Record and execute VS Code workflows (open file, edit code, save, run commands)

## Target
- **App**: Visual Studio Code
- **Type**: Native Desktop Application
- **Platform**: macOS / Windows / Linux

## Recordings

### run-2026-05-06-open-file
- **Scenario**: Open a file from the file browser
- **Steps**: Cmd+O → navigate to file → select → open
- **Status**: ✓ Complete
- **Notes**: Requires a project folder to be open first

### run-2026-05-06-find-replace
- **Scenario**: Find and replace text in file
- **Steps**: Cmd+H → enter search term → enter replacement → replace all
- **Status**: ✓ Complete, validated
- **Notes**: None

## Configuration
See `config.json` for app-specific settings.

## Running Automations

```bash
cd recordings/apps/vs-code

# Execute a recording
dare execute --run run-2026-05-06-open-file --live false

# Execute with parameters
dare execute --run run-2026-05-06-find-replace --live true --params "{\"search\":\"TODO\",\"replace\":\"DONE\"}"
```
